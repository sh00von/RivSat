# 🗺️ GIS Integration Guide: QGIS, ArcGIS, GeoTIFF, & Vector Layers

**RivSat** automatically generates Cloud-Optimized GeoTIFF (COG) rasters, CSV data reports, and GeoJSON spatial vector layers ready for spatial analysis in **QGIS**, **ArcGIS Pro**, and **Google Earth**.

---

## 1. Directory Structure of GIS Outputs

All processing outputs are saved in `outputs/<SITE_NAME>/`:

```
outputs/<SITE_NAME>/
├── rasters/                                  # Cloud-Optimized GeoTIFF Rasters
│   ├── S2_2023_Winter_Median_Turbidity_FNU.tif
│   ├── S2_2023_Winter_Median_TSS_mgL.tif
│   ├── S2_2023_Winter_Median_Chlorophyll_ugL.tif
│   ├── S2_2023_Winter_Median_CDOM_m1.tif
│   ├── S2_2023_Winter_Median_Salinity_PSU.tif
│   ├── S2_2023_Winter_Median_SecchiDepth_m.tif
│   └── S2_2023_Winter_Median_WaterMask.tif
├── turbidity_timeseries.csv                 # CSV Time-Series Reports
├── chlorophyll_timeseries.csv
├── multiparameter_grid_plot.png              # Publication PNG Figures
├── longitudinal_gradient.png
└── cross_transects.png
```

---

## 2. GeoTIFF Spatial Reference Properties

Every GeoTIFF generated by RivSat features standard GIS metadata:
- **Spatial CRS**: `EPSG:4326` (WGS 84 Geographic Coordinate System).
- **Pixel Datatype**: `Float32` (Single-band floating point raster).
- **NoData Value**: `NaN` (np.nan for background land pixels).
- **Compression**: `LZW` lossless compression.

## 3. Loading & Styling Rasters in QGIS

### 3.1. Import GeoTIFF Rasters
1. Open **QGIS**.
2. Drag and drop any `.tif` file from `outputs/<SITE_NAME>/rasters/` into the Map Canvas.

### 3.2. Recommended Color Palettes in QGIS:

| Parameter | QGIS Color Ramp | Interpolation |
| :--- | :--- | :--- |
| **Turbidity (FNU)** | `YlOrRd` (Yellow-Orange-Red) | Continuous Linear |
| **TSS (mg/L)** | `YlOrBr` (Yellow-Orange-Brown) | Continuous Linear |
| **Chlorophyll-a (ug/L)** | `YlGn` (Yellow-Green) | Continuous Linear |
| **CDOM ($a_g(440)$)** | `Copper` / `Spectral` | Continuous Linear |
| **Salinity (PSU)** | `Blues_r` (Reversed Blues: Dark Blue = Fresh, Light Blue = Saline) | Continuous Linear |
| **Secchi Depth (m)** | `Viridis` (Dark = Turbid/Shallow, Yellow = Clear/Deep) | Continuous Linear |

## 4. Vector Layers (`user_roi.geojson`, `centerline.geojson`, `stations.geojson`)

Vector layers stored in `./data/` can be loaded directly into QGIS as vector layers:
- `centerline.geojson`: Single or multi-part Polyline.
- `stations.geojson`: Point feature pins containing `station_name`.
- `user_roi.geojson`: AOI Polygon bounding box.
